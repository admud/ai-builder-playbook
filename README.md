# AI Builder Playbook

Practical prompts, workflows, and lessons from building AI products in public.

Use these playbooks as starting points, adapt them to your project, and ship
something.

## Playbooks

### Video and Motion

- [001 — Website to Video](tips/001-website-to-video.md)

  Create branded promotional videos with Codex and HyperFrames.

### Images and Portraits

- [002 — Cinematic Backlight Portraits](tips/002-cinematic-backlight-portraits.md)

  Create three reference-guided editorial portraits with a consistent
  backlight treatment.

### Agentic Coding

- [003 — Verify an Agent-Built Change](tips/003-agentic-coding-verification.md)

  Define done, exercise the change, and attach commit-specific evidence.

- [Agentic Coding Reference Log](references/agentic-coding.md)

  Track useful sources and trials separately from adopted practices.

## Using the Playbooks

1. Open a playbook.
2. Replace every `[PLACEHOLDER]`.
3. Run the prompt in the named tools.
4. Review the output before publishing it.

New playbooks use the [tip template](templates/tip.md).
